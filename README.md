#Pruebas
Puede acceder a los reportes de pruebas en la carpeta raiz, la general, ahi mismo se ven dos archivo uno coverage y otro eslint, el coverage solo dice index. Pero para que tenga mejro visualizacion de los reporte visite las siguientes carpetas.

Los reporte de pruebas se encuentran en als siguientes carpetas: matfi_backend/coverage/lcov-report está el archivo index.html, ese archivo muestra los resultados de coverage, para el reporte de codigo de eslint debemos ir a matfi_backend/tests y tomar el archivo que dice eslint-report.html.
